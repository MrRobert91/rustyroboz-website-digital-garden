# Local fonts

Latin WOFF2 subsets from Fontsource, version 5.3.0. These include Spanish accents.
Vendored to keep production builds independent of Google Fonts requests.
All fonts use the SIL Open Font License; each family license is included.

- @fontsource-variable/space-grotesk@5.3.0: https://registry.npmjs.org/@fontsource-variable/space-grotesk/-/space-grotesk-5.3.0.tgz
- @fontsource/ibm-plex-serif@5.3.0: https://registry.npmjs.org/@fontsource/ibm-plex-serif/-/ibm-plex-serif-5.3.0.tgz
- @fontsource-variable/caveat@5.3.0: https://registry.npmjs.org/@fontsource-variable/caveat/-/caveat-5.3.0.tgz
- @fontsource-variable/jetbrains-mono@5.3.0: https://registry.npmjs.org/@fontsource-variable/jetbrains-mono/-/jetbrains-mono-5.3.0.tgz

Cuentee turns a child's interests into an original illustrated story. A prompt can include their name, favourite animal or a topic they are learning about; within a few minutes the application produces a multi-chapter tale with a cover and an illustration for every scene. Stories remain available in the user's gallery and can be downloaded as a PDF.

There are two creation paths. Open mode accepts a free-form idea, typed or dictated by voice. Guided mode structures the request around an age group, protagonist, educational theme and mission, making it possible to combine a real narrative with subjects such as space, emotions or the water cycle. The application supports several visual styles and languages, and its downloadable books use OpenDyslexic to improve readability.

The generation pipeline first writes the complete story, then extracts a precise visual profile for every character and reuses those descriptions unchanged in each image prompt. That intermediate character sheet is what keeps details such as hair, clothing and species recognisable from one chapter to the next. Text, images and PDF generation run asynchronously so the interface does not remain blocked while the book is assembled.

The project also includes a child-safety evaluation layer. Its prompts establish an age-appropriate tone, while batches of generated stories are reviewed against criteria such as violence, adult material and disturbing content. The evaluation acts as an early-warning system for quality regressions rather than pretending that any automated safeguard is infallible.
